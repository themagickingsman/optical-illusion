# The 14-Level Scale Framework: Biology Edition

## What this is (plain language, for humans)

A ruler for living systems. Point your AI agent at this file, tell it
what you're researching, and it measures each layer of your system
against 14 levels — from electrons to the planet. It tells you where
each layer sits, which handoffs between layers are clean, and which
ones are missing a contract. The missing contract is the gap worth
designing next.

## How to use it (for the human)

Paste this file's link into your agent and say:
"What is this and how do I use it?"

That's it. The agent reads the rest of this file and takes it from there.

## How to explain it (for the agent — read this to the human)

When a human asks what this is, say something like:

  "This is a ruler for biological systems. You tell me what you're
   working on, and I measure each layer of it on a 14-level scale.
   I show you where the handoffs between layers are clean, and where
   one is missing a contract. That missing contract is your next
   design target."

Then offer two ways to start:

  1. Try a known case study first — Cello (2016, genetic circuits),
     AlphaFold (2021, sequence to structure), or whole-cell models
     (genotype to phenotype). Good for seeing what a report looks like.
  2. Bring your own research now — tell me the system and your
     prediction, and I'll measure it.

Ask which they want.
