The 14-Level Scale Framework: Biology Edition
What this is
A ruler for biological systems. Point it at a system you are researching. It places each layer of that system on one of 14 levels, from electrons to the planet. It shows which handoffs between layers are clean, which are skipped, and which are missing a contract. The missing contract is the gap worth designing next.

How to use it
Paste this file into your agent and say: "What is this and how do I use it?" The agent reads the rest and takes it from there.

Two ways to start:

A known case study first. Cello (2016), AlphaFold (2021), or whole-cell models. See what a report looks like.

Your own research now. Give the system and your prediction, and it is measured.

Columns:

Level / Octave Name: the stage and scale of the system. Levels 0–2 are physics beneath chemistry. 3–8 are the biological stretch. 9 and up are populations, the planet, and beyond.

Decimal Freq / Formula Base: the anchor for that level and how it is built from the others. Through the biological stretch, each level is built from the two beneath it: 1.10 + 1.78 = 2.88 (Orbitals + Bonds = DNA); 1.78 + 2.88 = 4.66 (Bonds + DNA = Tissue); 2.88 + 4.66 = 7.54 (DNA + Tissue = Self-Awareness).

Geometric Lock: the structure representing a stable arrangement at that level.

K_Scale: the scaling constant for that level and the direction it scales.

Scale Description: the direction and type of scaling.

For placement and handoff checks, use the Level, the Octave Name, and the order of the levels. Do all calculations and show the numbers used.

How to run it
Name the system and its layers. State the system, the question, and the data. If layers are unclear, propose them from the placement guide.

Predict first. Write what you expect at each layer and which handoff you expect to be cleanest. Record it.

Place each layer on a level. One line of reasoning per placement.

Read the neighbors. For each placed layer, name the level above and the level below and what each contributes.

Check the boundaries. For every handoff, state clean, skipped (jumps two or more levels with nothing in between), or missing (a handoff exists but no contract defines it).

Find the hidden layer and the contract. Name which levels sit behind an interface you never touch, and where intent goes in and structured results come out.

Report. Use the format below. List every gap found. If none, state that none were found and what was checked.

Report placements, handoffs, and gaps only.

The report format
text
SYSTEM:        <what was measured>
PREDICTION:    <what was expected, written before measuring>
PLACEMENT:     <layer -> level, one line of reasoning each>
NEIGHBORS:     <level above / level below for each layer>
BOUNDARIES:    <each handoff: clean | skipped | missing>
HIDDEN LAYER:  <which levels sit behind an interface never touched>
CONTRACT:      <where intent goes in and structured results come out>
MATCHES:       <where the system sits cleanly on the scale>
GAPS:          <skipped levels, missing contracts, deviations>
NEXT:          <what would need to exist before the next level up>
FRICTION:      <what was slow or confusing in the current tool>
The FRICTION line matters. Whatever could not be done easily is the next thing worth designing.

Examples
Cello (2016, genetic circuits). A logic specification goes in; a built genetic circuit comes out. Sixty circuits were built as designed, forty-five worked on the first test.

text
SYSTEM:        Cello genetic circuit design (2016)
PREDICTION:    Cleanest handoff is specification -> DNA
PLACEMENT:     spec -> L8 (intent) | design -> L6 (DNA / Helix) |
               assembly -> L5 (Molecular Bonds) | cell -> L7 (Tissue / Organs)
NEIGHBORS:     L6 sits on L4 + L5 and feeds L7
BOUNDARIES:    spec -> design: clean | design -> assembly: clean |
               assembly -> cell behavior: partial
HIDDEN LAYER:  circuit design and DNA assembly (L5-L6)
CONTRACT:      logic specification in, built circuit out
MATCHES:       the contract between intent (L8) and DNA (L6)
GAPS:          60 built as designed, 45 worked on first test, 15 did not;
               open handoff is DNA (L6) -> living cell (L7)
NEXT:          a contract for the L6 -> L7 handoff
FRICTION:      cell-context tuning is still done by hand
AlphaFold (2021, sequence to structure). An amino acid sequence goes in; a structure comes out. Sequence enters at L6 (DNA / Helix). The forces of L4 (Atomic Orbitals) and L5 (Molecular Bonds) stay hidden behind the input. Contract: sequence in, structure out.

Whole-cell models (genotype to phenotype). Genotype enters at L6; phenotype comes out at L7 (Tissue / Organs). The L6 → L7 handoff is the contract itself.

Placement guide
Level	Octave Name	What belongs here in biology
0-2	Void to Quark-Gluon	Physics beneath the chemistry. Usually a hidden layer under the model, not measured directly.
3	Atomic Nucleus	Isotopes, radiolabels, nuclear spin (NMR), radiometric dating.
4	Atomic Orbitals	Electron behavior: redox, fluorescence excitation/emission, spectroscopy, light capture, bioluminescence.
5	Molecular Bonds	Covalent and hydrogen bonds, base pairing, enzyme catalysis, ligand binding, folding forces, DNA assembly chemistry.
6	DNA / Helix	Sequences, genes, genomes, edits, gene circuits, expression programs, the information layer.
7	Tissue / Organs	Cells, organoids, tissues, organs, whole organisms as bodies.
8	Self-Awareness	Nervous systems, cognition, behavior, and the observer: researcher intent, judgment, specification.
9	Community	Populations, microbiomes, ecosystems, social behavior, epidemics.
10	Planetary	The biosphere, planet-wide cycles, the empirical anchor.
11-14	Solar System to Metaversal	Astrobiology and orbital drivers of biology (day length, seasons). If a layer is placed here, state what it contributes.
When two layers land on the same level, split them by what each contributes to the handoff. Do not merge them.

Running your own research
Simple run (one hour, no new lab work). Take the last pathway you worked on, DNA sequence to measurable phenotype. Write your prediction first, then:

text
Read this file. My system is [pathway, sequence to phenotype].
My prediction is [prediction]. Follow the protocol: place each layer
on a level, name the level above and below each one, mark each
handoff clean, skipped or missing, name the hidden layer and the
contract, and return a report listing every gap.
Harder run (a system across several scales). A viral vector (capsid, payload, target cell, tissue), an engineered circuit, or an organoid model:

text
Read this file. My system is [vector, circuit or organoid] with these
layers: [list them, with size, timescale or rate measured for each].
My prediction is [prediction]. Follow the protocol. Place every layer
on a level and say what the level above and below contribute. Flag
every skipped level, meaning anywhere the system jumps two levels
with no contract in between. Return a report with every gap and the
FRICTION line.
Read the FRICTION line. Whatever was slow, unclear, or missing is a complex system nobody has designed for yet.
